## Компоненты

### Backend (Сервер)

#### 1. **vpn_server.py** - Основной сервер
- Класс `VPNServer` - управление жизненным циклом сервера
- Класс `ClientHandler` - обработка каждого клиента
- Методы:
  - `_handshake()` - ECDH обмен ключами
  - `_authenticate()` - проверка пароля
  - `_handle_traffic()` - маршрутизация трафика

#### 2. **crypto_engine.py** - Криптография
- Класс `CryptoEngine`:
  - Генерация ключей Curve25519
  - Вывод сеансовых ключей (KDF)
  - Шифрование/расшифровка ChaCha20-Poly1305
  - Управление nonce

- Класс `HandshakeProtocol`:
  - Инициирование рукопожатия
  - Ответ на рукопожатие
  - Вывод ключа из пароля

#### 3. **obfuscation.py** - Обфусцировка
- Класс `TrafficObfuscator`:
  - HTTPS маскировка (TLS заголовок)
  - HTTP/2 маскировка (frame заголовок)
  - WebSocket маскировка (с XOR маской)
  - Random padding

- Класс `DPIBypass`:
  - Фрагментация пакетов
  - Вставка мусорных данных
  - Randomize MTU

- Класс `PacketSizeHider`:
  - Выравнивание размера пакета

#### 4. **traffic_router.py** - Маршрутизация
- Класс `TrafficRouter`:
  - Парсинг IP пакетов (v4/v6)
  - Маршрутизация TCP/UDP
  - Кеширование маршрутов

- Класс `ClientRoute`:
  - Создание сокетов для целевых адресов
  - Отправка пакетов в интернет
  - Управление TCP/UDP соединениями

### Frontend (Клиент)

#### 1. **main.py** - Точка входа
- Инициализация приложения PyQt6
- Создание главного окна
- Логирование

#### 2. **vpn_client.py** - Логика клиента
- Класс `VPNClient`:
  - Подключение к серверу
  - Аутентификация
  - Управление соединением
  - Статистика и мониторинг

#### 3. **ui/main_window.py** - Главное окно
- Класс `MainWindow`:
  - Три вкладки: Подключение, Статистика, Настройки
  - Обработка кнопок подключения/отключения
  - Обновление статистики в реальном времени

- Класс `ConnectionThread`:
  - Фоновый поток для подключения
  - Сигналы для UI обновления

#### 4. **ui/settings_dialog.py** - Диалог настроек
- Класс `SettingsDialog`:
  - Таймауты сокетов
  - Параметры буфера
  - Криптография
  - Логирование

#### 5. **ui/styles.py** - Стили
- Темный стиль для Windows 11
- Цветовая схема
- Размеры компонентов

### Shared (Общий код)

#### 1. **protocols.py** - Протокол VPN
- Enum `PacketType` - типы пакетов
- Enum `ObfuscationMode` - режимы обфусцировки
- Класс `PacketHeader` - заголовок пакета
- Класс `VPNProtocol` - создание/парсинг пакетов

#### 2. **utils.py** - Вспомогательные функции
- `hash_password()` - хеширование с PBKDF2
- `verify_password()` - проверка пароля
- `get_local_ip()` - получение локального IP
- Класс `RateLimiter` - ограничение частоты

## Протокол взаимодействия

### Структура пакета

```
┌─────────────────┬──────────────────────────────┐
│  Заголовок (8б) │     Payload (переменный)     │
├─────────────────┼──────────────────────────────┤
│ Type|Flag|Len|Seq│          Данные             │
│ 1б  |1б  |2б |2б  │                            │
└─────────────────┴──────────────────────────────┘
```

### Жизненный цикл соединения

```
1. HANDSHAKE_REQUEST
   Клиент → Сервер: {client_id, obfuscation_mode}

2. HANDSHAKE_RESPONSE
   Сервер → Клиент: {server_public_key}

3. KEY DERIVATION
   Обе стороны: ECDH + PBKDF2 → Session Key

4. AUTH_CHALLENGE
   Сервер → Клиент: random(32)

5. AUTH_RESPONSE
   Клиент → Сервер: PBKDF2(password)

6. DATA EXCHANGE
   Bidirectional: encrypted packets (ChaCha20-Poly1305)

7. KEEPALIVE
   Регулярные пакеты для поддержания соединения

8. DISCONNECT
   Любая сторона: graceful shutdown
```

## Поток данных

### На сервере

```
Входящие данные
    ↓
[Дешифровка - ChaCha20-Poly1305]
    ↓
[Дедебускировка - удаление заголовков]
    ↓
[Парсинг IP пакета]
    ↓
[Маршрутизация - TCP/UDP к целевому адресу]
    ↓
[Получение ответа]
    ↓
[Обфусцировка - добавление заголовков]
    ↓
[Шифровка - ChaCha20-Poly1305]
    ↓
Исходящие данные
```

### На клиенте

```
Приложение (браузер и т.д.)
    ↓
[Операционная система создает пакет]
    ↓
[Перехват сетевого интерфейса] (в реальной реализации)
    ↓
[Обфусцировка - маскировка под HTTPS]
    ↓
[Шифровка - ChaCha20-Poly1305]
    ↓
[TCP Socket на порт 443 сервера]
    ↓
Сервер VPN
```

```
4. DPI Bypass (фрагментация, маскировка)
   ↓

   ↓

   ↓

   ↓

```

## Производительность

### Оптимизации

- Многопоточность для обработки клиентов
- Буферизация данных (4KB по умолчанию)
- Кеширование маршрутов TCP/UDP
- Rate limiting для DDoS защиты
- Асинхронное шифрование

### Ограничения

- Максимум 100 одновременных клиентов (конфигурируемо)
- Таймаут 30 секунд на неактивность
- Keepalive каждые 20 секунд
